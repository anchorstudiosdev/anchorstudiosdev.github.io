Batch-rename Project assets and Hierarchy objects with a stack of rules and a live preview. Every row is checked before anything is written, swaps and case-only renames are handled for you, and an asset batch can be undone even after an Editor restart.

Quick Start

  1. Open the window: Tools > Anchor > Renamer > Open Anchor Renamer, Anchor Rename... in the Project or Hierarchy right-click menu, or Alt+R.
  2. Select what to rename: files or folders in the Project window, or GameObjects in the Hierarchy. The list in the window follows the selection.
  3. Add rules with + Add Rule. Each rule is a card on the left, and the preview on the right shows every new name as you type.
  4. Uncheck any row to skip it, then press Rename, or Ctrl+Enter (Cmd+Enter on macOS) anywhere in the window.

Nothing is written until you press Rename. The ? Help button in the window opens a short reference.

Sources

The two tabs at the top choose what the window renames.

  • Project Assets: the Project window's selection, folders dragged onto Sources, and a folder picked in the ☰ Browse panel. A folder adds the files inside it.
  • Hierarchy Objects: the Hierarchy's selection, and objects picked in the ☰ Browse panel.
  • ☰ Browse opens a tree inside the window: the folders of Assets, or the open scenes' Hierarchy. A pick there also becomes Unity's selection.
  • Include subfolders: also scan the folders inside a source folder.
  • Rename folders too: off by default. A selected or dropped folder is renamed itself, and with Include subfolders on so is every folder inside it. The Assets folder is never renamed.
  • Rename scripts too: off by default, so C# script files are left out of the list and the footer says how many were. Renaming a script's file does not rename the class inside it; rename a script in your code editor, which renames the class and every use of it.
  • Include children: in Hierarchy Objects, add every descendant of each selected object.
  • Freeze targets: the list stops following the selection, so it stays while you click elsewhere.

Rules

Rules run from top to bottom, and each one receives the name the rule above it produced.

  • Drag a card's grip, or use its ↑ and ↓ buttons, to reorder.
  • A card's checkbox turns its rule off without removing it.
  • Click a card's title to collapse it; a collapsed card shows a one-line summary.
  • Applies to, at the bottom of every card, limits that rule to the asset types you tick. Other rows pass through it unchanged.
RuleDoesMore than one
Override NameReplaces the whole name with a template.No
Find & ReplaceReplaces text, with Regex, Match Case and Whole Word options.Yes
Prefix / SuffixAdds text before and after the name.Yes
Format Caselower, UPPER, Title, camelCase, PascalCase, snake_case or kebab-case.No
Quick CleanupRemoves spaces, numbers or special characters, and collapses repeated _, - and spaces.Yes
Trim CharactersRemoves a number of characters from the start and the end.Yes
NumberingAdds a running number before or after the name.Yes
  • Override Name and Format Case rewrite the whole name, so a stack holds one of each. Choosing one you already have scrolls to it.
  • With Regex on, $1 in the replacement is the first capture group. An invalid pattern is outlined in red and leaves names unchanged.
  • Format Case and Remove special characters keep letters and digits of every script.
  • Remove numbers removes every digit, not only a number at the end.
  • Numbering has Position, Start, Step, Digits and Separator. Replace existing trailing number is on by default: Car_10 becomes Car_04. With it off the new number follows the old one: Car_10_04.

The order matters. Quick Cleanup (Remove numbers) above Numbering turns Card_07 into Card_001; below Numbering it removes the number that was just added.

Tokens

Override Name's template, Find & Replace's replacement, and Prefix / Suffix accept tokens. Click { } beside the field to pick one by name, or type it. The line under the field shows the result for the first item in the list.

Preview

  • Each row shows the current name, the new name with the changed part highlighted, and a status: Ready, Unchanged, or what is wrong.
  • The search box, the type filter and the All / Ready / Conflict / Unchanged chips only choose which rows are shown. Rename applies to every checked row, shown or not; the footer has the count.
  • The checkbox above the list checks or unchecks every row shown, and Invert flips them.
  • Click a row to ping its asset or object.

Sort and counters

Sort sets the order of the list by Name, Type or Path, and counters follow it: {n}, {i} and Numbering count the checked rows from the top of the list down.

  • By Name, a number inside a name counts by its value, so Card_2 comes before Card_10.
  • By Path, Hierarchy objects are listed in Hierarchy order.
  • An unchecked row takes no number.
  • A rule limited by Applies to counts only the rows it applies to.

Safety

  • Conflicts: two rows that would get the same name, or a name another asset already has, are marked and not renamed. Resolve Conflicts gives each the first free _1, _2, ... variant.
  • Swaps and cycles: renaming A to B while B becomes A works, and so does a longer chain or cycle.
  • Case-only renames: Player to player works on Windows and macOS.
  • Special folders: a folder can't be renamed to or from Editor, Resources, Plugins, StreamingAssets, Gizmos, Editor Default Resources or Standard Assets.
  • Illegal names: for an asset, an empty name, illegal characters, a leading or trailing space, a trailing dot and Windows device names such as CON are refused. A Hierarchy object's name only has to be non-empty.
  • Read-only packages: assets in an immutable package are never renamed.
  • If an asset can't take its new name after all, it keeps its old one, and the Console says why.

Undo

  • Hierarchy objects: one Ctrl+Z reverts the whole batch.
  • Assets: Unity's Undo doesn't cover asset renames. Undo Last Rename reverts the last asset batch, and then the one before it, up to the last 50. It works after a script recompile or an Editor restart, and after the assets have been moved.
  • An asset that can't be renamed back, because something else has taken its old name, stays in the batch. Free the name and press Undo Last Rename again, or choose Forget to drop what is left so the batch before it can be reverted. An asset deleted since is skipped.

Presets

The Presets ▾ menu loads one of the built-in stacks, saves the current rule stack under a name, loads a saved one, and deletes one. Saving under an existing name replaces it. Presets are per user and available in every project on the machine.

The built-in presets are read-only. Loading one fills the rule stack with a copy that you can edit and save under your own name.

PresetWhat it does
Clean importsRemoves spaces and special characters, collapses repeated separators, then sets PascalCase.
snake_caseSets snake_case and trims stray separators.
Type prefixesAdds tex_ to textures, mat_ to materials, sfx_ to audio clips and prefab_ to prefabs. A name that already has its prefix is left alone, so running it twice changes nothing.
Number a setNumbers the list in its sort order with two digits and an _ separator, replacing a trailing number.
Strip junkRemoves trailing (1), _copy, _final and _v2 style endings, however many are stacked.

Settings

The Renamer page under Preferences > Anchor has the module's switch and its shortcut. Everything else is in the window and is remembered per user.

  • With the module off, its menu items are disabled and Alt+R does nothing.
  • Alt+R is registered with Unity's Shortcut Manager as Anchor > Renamer > Open Anchor Renamer, where it can be rebound or removed.

Compatibility

  • Anchor Renamer is editor-only. It adds nothing to a build.
  • The undo history of asset renames is kept in UserSettings/Anchor/RenameJournal.json, in the project. GitHub's Unity .gitignore leaves UserSettings out of version control.
  • Presets, the rule stack and the window's layout are kept in the Editor's preferences on your machine.
