Settings: Edit > Preferences > Anchor > Hierarchy (on macOS, Unity > Settings > Anchor > Hierarchy) or Tools > Anchor > Settings

Enhanced Unity Hierarchy window decoration with full-width row colors, parent-child tree connector lines, custom and auto-resolved component icons, inline activation checkboxes, right-aligned component minimaps with floating mini inspectors, keyboard shortcuts, toolbar extensions, and interactive layer/tag columns.

Features

Row Colors, Gradients & Notes

  • Full-width background colors with per-selection Gradient (default) or Solid fill modes stored in scene-associated AnchorHierarchyData.
  • Alternating zebra striping when no explicit color is assigned.
  • In-line row notes and comments (// Note) with adaptive background-aware contrast.
  • Auto-contrasted text labels (light/dark) based on background fill brightness.
  • Alt-click any row to open the color palette, icon browser, and note editor.

Subtree Statistics Tooltip

  • Rich metrics tooltip displayed on GameObject name hover:
    • Total recursive children count (active / inactive breakdown).
    • Component breakdown by category (Colliders, Renderers, Scripts, UI, Physics, Audio, etc.).
    • Total geometry complexity: combined Mesh triangle and vertex count from MeshFilter and SkinnedMeshRenderer.

Tree Connector Lines

  • Draws vertical and horizontal connector lines linking parent GameObjects to their children.
  • Depth-aware alignment matching Unity's foldout arrows.

Row Icons & Auto Component Icons

  • Three icon modes: All, Hide Default, and Hide All.
  • Auto Component Icons: Automatically replaces Unity's generic GameObject/prefab icon with the object's first meaningful component icon (e.g. Camera, Light, AudioSource, custom script).
  • Custom icon picker with search across built-in Unity icons.

Inline Activation Checkbox

  • Enables/disables GameObjects directly from the Hierarchy.
  • Placement options: Left (next to foldout arrow) or Right (adjacent to component minimap).
  • Modes: Always, On Hover, or Disabled.

Component Minimap & Mini Inspector

  • Renders component icons along the right edge of each Hierarchy row, showing fewer when the name needs the room.
  • Alt-click any component icon in the minimap to open the Component Mini Inspector:
    • A lightweight floating window displaying the component's serialized fields and method action buttons ([Button] / [AnchorButton]).
    • Auto-close: Automatically closes when losing focus unless pinned.
    • Pin Toggle: Pins the window open on screen for multi-component inspection.
    • Multi-tier positioning: Anchors smoothly near the clicked icon, mouse cursor, or active window without spawning off-screen or at (0,0).

Header Rows

  • Renders GameObjects named --- Label --- or // Label as full-width separator banners for visual grouping without real scene reparenting.

Empty Space Script Drop

  • Drag a single script asset onto the empty space below the last Hierarchy row to spawn a new GameObject carrying that component, named after the script's type.

Hover Shortcuts

Hover the cursor over any row in the Hierarchy and press:

  • E: Expand / collapse children.
  • Shift+E: Isolate / collapse all other sibling branches.
  • Shift+A: Toggle active state.
  • F: Frame / ping in Scene view.

Collapse All Shortcut

  • Shift+Z collapses every object in the Hierarchy, or expands them all again once everything is collapsed. It does what the toolbar's collapse button does, whether or not the toolbar buttons are shown.
  • Works from any window, with no click into the Hierarchy first. With more than one Hierarchy open, it acts on the one under the cursor, else the focused one.
  • Registered with Unity's Shortcut Manager: rebind or remove it in Edit > Shortcuts > Anchor > Hierarchy.

Scene Headers & Quick Switcher

  • Adds a scene selector dropdown arrow directly on scene header rows in multi-scene workflows.
  • Quick Scene Switcher panel with pinned favorites, bold active scenes, drag reordering, and dockable window mode.
  • Clicking a scene opens it on its own. From a scene header's arrow while the Hierarchy lists more than one scene, it replaces only that scene, keeping its place, its loaded state and whether it is the active scene. Shift+Click adds the scene alongside the listed ones.

Layers & Tags Columns

  • Interactive columns on the right edge of the Hierarchy:
    • Layers Column: Shows current layer; click to open popup dropdown and reassign layer with Undo support.
    • Tags Column: Shows current tag; click to open popup dropdown and reassign tag with Undo support.
    • Top Header Strip: Displays Layers | Tags headers above the columns on scene header rows.
    • Label Clipping: GameObject names clip cleanly (TextClipping.Clip) to ensure long names never bleed into columns.

Settings

The Hierarchy page under Preferences > Anchor, one foldout section per group:

Row Appearance

  • Row Icons: All / Hide Default / Hide All.
  • Auto Component Icons: Toggle automatic component icon resolution.
  • Tree Lines: Toggle parent-child tree connector lines.
  • Zebra Striping: Toggle alternating row background tinting, with Even Row Color and Odd Row Color under it.
  • Header Rows: Toggle --- Header --- banner rendering.
  • Row Notes: Toggle in-line textual row notes and comments.
  • Subtree Statistics Tooltip: Toggle recursive metrics and triangle/vertex count tooltips.

Row Controls

  • Activation Toggle: Always / On Hover / Disabled, with Toggle Position (Left / Right) under it.
  • Component Minimap: Toggle the right-side component icon strip, with Max Icons (1–10) under it.

Toolbar & Panels

  • Toolbar Buttons: Collapse/expand-all, scene switcher, and bookmarks buttons on each Hierarchy window's toolbar, folding into one ⋮ menu when the window is narrow and hidden while the search field fills the toolbar.
  • Bookmark Bar: Bookmarked GameObject chip strip pinned at the bottom of each Hierarchy window.
  • Bookmark History: A History column of recent selections in the Bookmarks panel.
  • Panel Brightness: Adjust floating window background brightness.

Tag & Layer Columns

The section's checkbox switches both columns on or off.

  • Hide When Crowded: Hide a row's columns when they would cover its name. Off, they shrink instead.
  • Min Label Width: Minimum width kept for GameObject names; with Hide When Crowded off, the columns shrink to keep it.
  • Column Alignment: Compact packing or a Fixed Grid of column tracks.
  • Column Placement: Where the columns sit relative to the component minimap.
  • Display Mode: Columns always shown, or only on the hovered row.
  • Column Headers: Toggle top Layers | Tags column header bar.
  • Layer Column / Tag Column: Show the column, with Select On Click, Hide 'Default' / Hide 'Untagged' and Width under it.

Shortcuts

Lists the shortcuts with their current bindings. The section's checkbox turns Shift+Z and the hover shortcuts E, Shift+E, Shift+A and F on or off together.
