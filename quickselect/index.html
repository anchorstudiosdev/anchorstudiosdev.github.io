Bookmark frequently used GameObjects, assets, and folders into named pages, jump back to recent selections, and bind any object to a persistent Shift+1–9 speed dial — from one searchable panel that docks or pops up on a hotkey.

Open it with Alt+Q, by holding Ctrl+Q for a temporary peek, or from Tools > Anchor > Quick Select > Open Quick Select Panel.

If Anchor Hierarchy is installed too, the two share one list of bookmarks: anything bookmarked in Hierarchy's Bookmarks panel or bookmark bar shows up here, and anything bookmarked here shows up there.

Features

Paged Sidebar

  • Bookmarks organize into named pages listed down the left side of the Bookmarks tab.
  • Unsorted is a virtual page computed on the fly, holding every bookmark not filed into a real page.
  • Create with + New Page at the bottom of the sidebar, rename by double-clicking a page name, delete with ✕ (its items fall back to Unsorted rather than being unbookmarked).
  • Right-click a page to rename it, remove all of its bookmarks, or delete it with or without its bookmarks. Unsorted offers the removal. Both removals ask first.
  • Reorder by dragging a page's handle, or with the ▲ / ▼ buttons — both stay within the page's own pinned/unpinned group.
  • Pin to top with 📌: pinned pages group above Unsorted under a PINNED PAGES divider, and the rest under PAGES. Both dividers appear only while at least one page is pinned.
  • Sidebar is drag-resizable between 150px and 320px, with the width persisted, and its rows alternate in color.

Recent Tab

  • Lists your recent selections, shared with Anchor Hierarchy's Bookmarks panel when it is installed.
  • Shows the last N distinct selections, N configurable up to 25.
  • Star any recent entry to promote it into bookmarks without leaving the tab.
  • An entry whose object no longer resolves is dropped rather than chased, since nothing here was placed deliberately.

Rows

  • Icons show Unity's stock icon. With Anchor Hierarchy installed, a scene GameObject shows its Hierarchy row icon instead.
  • Origin tag on the right: the scene name for a scene GameObject, Project for an asset, or <scene> (closed) for a bookmark whose scene is not currently open.
  • Closed-scene bookmarks keep the name they were bookmarked under, dimmed. Clicking one offers to save the open scenes, opens its scene and selects the object.
  • Missing entries render italic and red with a tooltip distinguishing "its scene isn't open" from "it may have actually been deleted", rather than silently vanishing.
  • **↗ Open** does what double-clicking the object does — a script opens in the code editor, a prefab opens Prefab Mode, a scene opens it — through AssetDatabase.OpenAsset, the same generic API Unity's own Project window uses. A scene GameObject has no asset to open, so it is selected and framed in the Scene view instead.
  • Click a row to select and ping it; right-click to move it to another page; star to remove its bookmark; drag the handle to reorder within the page.

Adding Bookmarks

  • Drag GameObjects, assets, or folders onto the panel to bookmark them into the current page. A drop while the Recent tab is showing switches to Bookmarks, on the page the objects went to.
  • Right-click a folder in the Project window and choose Anchor Bookmark Folder Contents... to bookmark what sits directly inside it in one action, picking the destination page from a menu. A subfolder becomes one folder bookmark. Above 50 items it asks first.
  • Star an entry in the Recent tab.

Speed Dial

  • Shift+1 through Shift+9 bind to one specific object each, persistently — not to a page-relative position, so a slot keeps pointing at the same thing as pages are reordered.
  • Scene GameObjects bind per scene, stored in a .AnchorQuickSelect.asset under {sceneFolder}/Anchor/QuickSelect/, so the same key can mean a different object in a different scene. Saving a scene with no slot bound deletes its asset.
  • Project assets bind project-wide, keyed by asset GUID, so a binding survives the asset being renamed or moved.
  • The same key both assigns and recalls: pressing it with something selected fills an empty slot, pressing it otherwise selects and pings whatever is bound.
  • Reassigning an occupied slot from the keyboard requires opting in (Allow Overwrite), so a stray keypress cannot silently replace a deliberate binding. The Preferences slot fields can always reassign, since dragging onto a specific field is already deliberate.

Window Modes

  • Pinned: a real dockable EditorWindow that lives in the layout. Its size and position are remembered independently of the popup form, and the redundant chrome bar is dropped since the window tab already provides a title and close button.
  • Popup: an auto-closing dropdown, used by the Ctrl+Q peek.

Shortcuts

ShortcutAction
Alt+QOpen the panel, pinned
Ctrl+Q (hold)Show the panel as a temporary overlay; closes on release
Shift+1–9Speed dial: recall the bound object, or bind the current selection

(Ctrl is the Control key on every platform, macOS included.)

All of these are Unity [Shortcut] / [ClutchShortcut] entries registered under Anchor/Quick Select/..., so they are listed in Edit > Shortcuts, individually rebindable, and covered by Unity's own conflict detection. Alt+Q follows the suite convention that Alt opens a window.

Settings

The Quick Select page under Preferences > Anchor, one foldout section per group:

Panel

  • Item Size: Height of each row (20px–48px). Icons and label text scale to match.
  • Hold-to-Peek (Ctrl+Q): Toggle the hold-to-show overlay. Alt+Q opens the panel regardless of this.

Recent Tab

The section's checkbox shows or hides the Recent tab. Selections are recorded either way; this governs display only.

  • Max Shown: How many entries the Recent tab lists (1–25).

Speed Dial

  • Allow Overwrite: Let Shift+N replace an already-bound slot. Off by default.
  • Confirm Before Overwriting: Ask before replacing an already-bound slot with a different object.
  • Slots 1–9: A drag-and-drop object field per slot, each showing its live key binding.

Maintenance

  • Clear All Bookmarks...: Removes every bookmark and page assignment, after a confirmation.
  • Clear Recent History...: Removes every Recent entry, after a confirmation.

Shortcuts

Lists Quick Select's bindings, with Open Unity Shortcuts Window for rebinding them.
